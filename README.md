
# Lotus-3D

Lotus-3D is a computer graphics project focused on **3D modeling, texturing, and rendering** using Blender.

The project explores the creation of 3D assets, visual composition, and digital content through practical computer graphics techniques.

## Technologies & Tools

- **3D Software:** Blender
- **Techniques:** 3D Modeling, Texturing, Rendering
- **File Formats:** BLEND, FBX, OBJ, GLB
- **Version Control:** Git, GitHub

## Project Highlights

- Creation and editing of 3D models
- Application of materials and textures
- Rendering and visual presentation
- Exporting 3D assets in different formats

## Project Files

The repository includes Blender project files, exported 3D models, textures, and rendered images.
